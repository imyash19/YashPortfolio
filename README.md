# Yash Roy — Data Analyst Portfolio

A dark, cinematic, scroll-driven personal portfolio built with plain HTML, CSS and JavaScript (GSAP + ScrollTrigger for the 3D scroll effects).

## Structure
```
index.html
css/style.css
js/script.js
assets/
  hero-desk.jpg     - desk photo, hero section
  profile.jpg        - portrait, about + gallery
  Yash_Resume.pdf     - downloadable resume
```

## Deploy on GitHub Pages
1. Create a new repository (e.g. `portfolio`).
2. Upload all files/folders in this zip, keeping the same structure.
3. Go to **Settings → Pages**, set Source to the `main` branch, root folder.
4. Your site will publish at `https://<username>.github.io/<repo-name>/`.

## Run locally
Just open `index.html` in a browser, or serve it:
```
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.

## Notes
- Update the GitHub project links in `index.html` (search `View on GitHub`) to point at your individual repos once they're live.
- Swap `assets/Yash_Resume.pdf` any time you update your resume — the filename stays the same so the links keep working.
